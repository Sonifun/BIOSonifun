# Telegram Bot

Этот проект представляет собой простого Telegram бота, созданного с использованием библиотеки aiogram.

## Функционал

Бот имеет главное меню с тремя опциями:
- **Обо мне**: Показывает информацию о вас.
- **Мои программы**: Показывает информацию о ваших программах.
- **Как связаться со мной**: Показывает контактную информацию.

## Установка

1. Клонируйте репозиторий или скачайте файлы.
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Получите токен бота от [BotFather](https://t.me/botfather) в Telegram.
4. Создайте файл `.env` на основе `.env.example` и укажите ваш токен:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```
5. Запустите бота:
   ```
   python main.py
   ```
5. Запустите бота:
   ```
   python main.py
   ```

## Настройка

- Измените текст в обработчиках callback для персонализации информации.
